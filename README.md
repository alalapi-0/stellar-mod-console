# Stellar Mod Console

剑星（Stellar Blade）的非官方开源 MOD 管理系统。目标是在一个游戏内控制台中管理服装、外观、镜头、物理、动画和玩法 MOD，并用同一套规则阻止互斥组合、提示前置与性能影响。

**已进入执行阶段，目前提供只读输入调查工具，尚无可安装的游戏内管理器。** 当前验收与下一动作见 PROJECT_STATE.json；哈希、解码和作者说明不能代替游戏兼容测试。

开发目录位于用户的 Projects 项目根，与其他项目同级。游戏、下载包、第三方工具留在原目录，用本机配置路径引用。仓库不会收录玩家 MOD、游戏资产、存档、账号数据或未知授权代码。

## 为什么统一管理仍需要互斥

一个入口可以管理多个 MOD；它无法改变加载器 ABI、同名资源覆盖或身体/骨骼不匹配的事实。同一个冲突组只能选一项。经过验证的运行接口可以即时调整；其他项显示“下次安全时应用”“需重启”或“缺少条件”。未知组合不能被显示为已兼容。

“一个体型适配所有衣服”作为逐件适配和动作测试目标推进。控制台应自动匹配身体、材质和前置，不能假装不同作者资源天然无穿模。

## 源码结构

`src/catalog` 清单；`src/policy` 兼容规则；`src/adapters` 工具适配；
`src/runtime` 游戏内桥；`src/ui` 玩家界面；`src/companion` 游戏外部署。
只读扫描与验证命令见 [清单模块](src/catalog/README.md)。其他模块仍按路线图推进。
