# 验证与恢复计划

本页由执行者维护验证方法，状态只放 PROJECT_STATE.json。没有现成功能测试或运行命令；它们在相应实现轮创建。测试应验证真实风险与行为，不能只是复述实现。

## 分层证据

1. **静态**：归档完整、三件套/依赖/命名空间/资源ID/文件路径、规则覆盖、许可。哈希相等证明字节相等，不证明运行兼容。
2. **启动**：确切游戏/build/loader/选项组合能启动、初始化、读档。保留错误/失败方法，不升级成全功能通过。
3. **操作与视觉**：游戏画面内真实快捷键/输入/选择/回读、服装动作、材质、物理、镜头、参数效果。
4. **状态与恢复**：过场、战斗、死亡、换图、对象销毁、外部工具修改、应用中断和回滚。
5. **性能**：同保存场景和画质下菜单关闭/打开、基础/重度配置对照帧时间/显存/内存，区分实测和作者声明。
6. **发行**：全新路径/用户、支持平台、安装升级卸载、依赖缺失、文件移动与非ASCII路径。

每份证据记录输入与代码版本、激活组合、检查和真实结果。合成/无游戏测试与真实游戏分开；不能以外部窗口截图替代 A05。

## 完整覆盖而非抽样冒充全部

R01 冻结包/MOD/变体/组件/选项分母。静态清单全覆盖；早期视觉/功能抽样只用于缩小失败面，明确未测数量。R21–R26 按稳定 ID 执行所有承诺支持选项的规定场景，不能用“代表性通过”计成逐项验证。

不要求遍历全部组合的指数空间：冲突图检查不变量和已知最小坏组合，运行测试覆盖单项、关键联动、互斥转换与高风险组合；公开支持范围只取实际验收版本。若长重复清单符合全局 sharding 条件，先按相关策略冻结互不重叠分区；不抢独立顶层任务容量。

## 关键负例

- 同一目标的两个变体，loader 家族同时选取，缺依赖/DLC，不支持 ABI，重复 CNS UniqueFitID/Container ID。
- 相机/物理/移动/自动换装的两个写入者，快捷键双绑定。
- UI 禁用后配置导入/快捷键/随机切换仍尝试绕过；后端必须同样拒绝。
- 缺少一个三件套文件、源移动、损坏/未完成下载、恶意归档路径、配置非法参数。
- 部署中断、原文件被其他程序修改、游戏突然启动、配置切换失败；绝不删其他拥有者文件。
- world/actor 已失效、过场、死亡、换图；延后可取消，关闭恢复输入且不破坏其他菜单。
- Body/material/physics 不匹配、参数边界与重置、CPU/GPU负载上升和资源释放。

## 本机真实数据保护

执行前核实测试存档/配置的隔离方式及原文件精确前像，不能假定测试不写游戏存档。禁止修改 Steam 账号或 Cloud 设置来简化测试；没有可用隔离方案时仅运行不触及真实进度的验证并保留 NOT_RUN。

已授权的精确安装目标可恢复本轮自己的原像；用户期间的游戏进度、外部改动和其他任务不能回滚。崩溃后先核对状态再重试，不盲目重复相同失败。测试只关闭本任务明确启动的游戏/工具实例。

## 发布检验

从干净玩家环境配置路径、安装外部前置、启动控制台、执行互斥与换装、退出部署、升级、卸载和恢复。Linux/Proton 与原生 Windows 独立列结果，平台未测不能叫跨平台通过。

个人 M1 和公开 M2 分别验收；所有未支持/未测/缺许可项保留数量与原因。具体 Release/Nexus 发布必须是已验候选获授权后的最终动作。
