# 只读兼容策略

`static`检查候选组件、互斥和已知坏组合；`interfaces`调查调用、控件和文件读写声明；`resources`解析有界资源元数据；`profiles`计算请求与当前配置的依赖闭包、增加/移除和冲突；`installed`核对调用者明确提供的安装索引、字节摘要和命名空间。这些入口不部署、保存配置或启动游戏。

公共CLI及精确参数以各模块`--help`为准。调用者只提供自己获授权的源、清单和私有输出；真实账号、存档、MOD原件与原始运行资料不进入Git。独占输出不覆盖现有文件，源路径、并发变化、损坏记录及未知来源继续拒绝或保持未知。

整包、单组件、容器、脚本和加载器分别计数。只选择容器/加载器不隐式选择同包脚本；默认前置不自动选版本，显式提供者只展开候选闭包。未知前置仍阻塞；同名、相同摘要、声明存在或静态引用不能证明运行版本、ABI、启用状态、写入权或实际兼容。只读预览can_apply=false。

安装核对分别记录原包与安装命名空间，重新核对已登记文件、链接、大小写碰撞与未登记项；日志与存档备份不会变成可部署来源。`mods.txt`声明、Lua/C++入口、enabled.txt及实际加载各自取证。原配置尾逗号恢复只用于调查元数据，不修改原件；重复JSON键拒绝。

测试使用自有合成输入：`python3 -B -m unittest discover -s tests -p 'test_profiles.py'`及对应模块测试。完整用户安装盘点、历史报告与当前选用配置留在本机原State和私有证据；公开源码不继承这些主机事实。真实冷启动、身体/资源配套、运行恢复和玩家接受另行验收。
